# VR9 Updates

Atualizacoes e instaladores dos programas da VR9 Systems.

## Instaladores (sempre a versao mais recente)

- VR9 Beauty: https://github.com/richardnunesrs/VR9-Updates/releases/download/beauty-instalador/VR9Beauty-Setup.exe
- VR9 Auto: https://github.com/richardnunesrs/VR9-Updates/releases/download/auto-instalador/VR9Auto-Setup.exe

Cada atualizacao e publicada como release com a tag `<programa>-v<versao>` (ex.: `beauty-v1.8.0`, `auto-v1.1.0`) e e assinada digitalmente; os programas instalados conferem a assinatura antes de instalar.
